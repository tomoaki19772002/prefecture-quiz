# 都道府県クイズ 2分チャレンジ

スマホ向けの都道府県クイズ。`index.html` を開くだけで遊べます。

- 地図上で光った都道府県を6択で当てる → 続けて県庁所在地を6択で当てる(都道府県をまちがえたらスキップ、地図上に赤丸が点滅)
- 正解 +1 / まちがい −1(まちがえると正解を表示)、制限時間 2分
- 残り時間・ポイントをリアルタイム表示、BGM・正解音・不正解音あり(音はWeb Audioで合成)

## 地図データ

[dataofjapan/land](https://github.com/dataofjapan/land) の都道府県GeoJSONを簡略化して `map-data.js` にしています(沖縄は左上に移動して表示)。
- ハイスコアTOP3はブラウザ(localStorage)に保存されるため、端末ごとの記録です
